# 首页动效 · 2026-10-26

这一版借鉴 AdventureX 的品牌表达方向，围绕 FDE Club 的城市共创与企业需求重做首页节奏。保留真实城市状态、现有业务入口和后台数据来源，没有新增外部动画依赖。

## 配色

2026-11-20按用户要求，以 [FDE 官网](https://fde.com.ai/) 主色和 [WAIC 官网](https://www.worldaic.com.cn/) 渐变替换上一版黑橙方案。核对两站公开 CSS 后采用：

- FDE：品牌蓝 `#1d5cff`、悬停深蓝 `#0b3fd0`、海军蓝 `#0a1120`、白色 `#ffffff`、浅灰 `#f7f8fa`。
- WAIC：装饰渐变 `#506bff → #a350ff`、浅色渐变 `#f0f4ff → #f2efff`。
- 深色首屏标题使用较亮的蓝紫渐变，浅色区文字使用加深版本；小字号按钮维持品牌蓝底白字，确保可读性。

颜色集中在 `src/app/theme.css`，覆盖首页、内页、表单和后台。深色区单独设置文字与边框变量，Canvas 读取同一组蓝紫颜色变量。城市网络、滚动色带、合作流程与产业协作区沿用现有动效。成功和失败仍保留独立语义色。

## 实现

- `src/app/motion.css`：首页视觉覆盖、标题分段入场、横向文字带、卡片反馈和响应式布局；通过 `.experience-home` 限定首页样式。
- `src/components/city-sphere.tsx`：装饰性 Canvas 球体。城市名称和链接仍是来自服务端数据的 HTML。桌面约30fps，手机约20fps，并降低点数、线段数及分辨率。离屏及后台标签页暂停。
- `src/components/process-journey.tsx`：五步合作流程。桌面左侧悬停，右侧正常滚动，显示当前阶段；按钮可直接定位步骤。手机使用单栏，所有步骤始终可读。
- `src/components/motion.tsx`：滚动呈现、指针光晕、动效开关。
- `src/lib/motion-preference.ts`：同页、跨标签页和系统偏好同步。系统减少动态效果优先，用户暂停选择保存在本地浏览器；存储不可用时保留内存状态。

不锁定页面滚动，不拦截触屏手势。禁用脚本时保留全部正文和业务链接，球体为装饰，不承载唯一信息。
